# Sparks replace XP

Star Quest needed a currency that lights Stars and rewards Comebacks. Keeping XP and adding Sparks would have given Players two progress numbers next to Score, and `PLAN.md` rules out extra reward systems. So Sparks replace XP everywhere: every activity that earned XP earns Sparks, the weekly XP Board becomes the weekly Sparks Board, and lighting a Star is just earning enough Sparks in one Star round. We chose a rename over a separate in-Star currency because kids should never have to work out which number matters.

## Consequences

- Copy, badges, quests and the weekly Board all say Sparks; "XP" disappears from the app.
- Existing totals carry over, so the weekly Board and its cap are migrated rather than reset.
- Spark values inside a Star must sit on the same scale as everything else that earns Sparks.
