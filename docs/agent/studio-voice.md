# Studio voice

Read aloud plays prerecorded audio from the voice host, `https://voice.learnvedicmath.com/` (an R2 bucket with a custom domain; design D17, owner decision L8), else the device's own voice.

- The studio audio is never committed (the Sutra name clips in `sounds/` are the one committed audio, and `build.py` rejects audio anywhere else). It is a GitHub Release archive (`voice-<hash>`) named with its SHA-256 by the generated `js/voice-index.js`, which also names the voice host (`base`).
- The CI `voice-upload` job (`tools/voice/r2-upload.mjs`, on every push to `main`) downloads the archive, checks its SHA-256 and the hash in each hashed file name, uploads only objects the bucket does not have (with `Cache-Control: public, max-age=31536000, immutable`, never overwriting or deleting), then checks that every file the index names is in the bucket. The `deploy` job needs it, so the site never names voice files that are not there yet. Until R2 is set up (`vars.R2_ACCOUNT_ID` empty) the job is skipped, CI builds with `build.py --voice off` (no voice host anywhere in the site) and the deploy goes ahead with the device voice; a failed voice upload always blocks the deploy.
- The recording tools are repo-only in `tools/voice/` (`lines.mjs`, `record.mjs`, `publish.mjs`; steps in the repo `README.md`). A change to any spoken line needs a re-record and publish in the same PR, or `test/voice-coverage.test.mjs` fails for Explorer lines.
- Keys and tokens come only from the shell (`GOOGLE_TTS_TOKEN=$(gcloud auth print-access-token)`), never a file. Keep the spend guard in `tools/voice/voice-lib.mjs` ($300 a month, $50 a run, 300 requests a minute).
- The game never calls a speech service, and `build.py` fails on a provider host or key in a published file.
- `sw.js` keeps voice files cache first in `lvm-voice`, a cache every deploy keeps: up to 4,000 whole lines, and one copy of the line set, clip directory and each pack (a re-record's new copy replaces the old one; `app/src/sw/sw-voice.test.ts`).
- The Family helpers' voice samples (`tools/voice/family-samples.mjs`, owner-run, `GO=1` to spend) write only to the git-ignored `tools/voice/out/family-samples/`; the listening page is `docs/prototypes/family-helpers/listen.html` (README, "Family helper voice samples"). Their lines stay text only until the full recording.
- End-to-end runs before the voice host is live: `E2E_VOICE_ORIGIN` points the tests at another copy of the files (`docs/agent/e2e.md`).
