# Spec Delta

## ADDED Requirements

### Requirement: The note describes online Duels
The parent note SHALL say, in the words of the Player's Mode, that online Duels send only the Player's made-up Nickname, avatar color, League and taps, that there is no chat or typed text, that nothing about a Duel is kept more than 10 minutes after it ends except reports (30 days, with no names), that Players under 13 can only duel friends by code, and how Report and Block work.

#### Scenario: Grown-up reads the note
- **WHEN** a grown-up opens the parent note in any Mode
- **THEN** it says what an online Duel sends, that there is no chat, how long anything is kept, and that under-13 Players can only duel friends by code
