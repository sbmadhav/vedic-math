# Tasks

Built only after the owner approves this change (AGENTS.md); merging its pull request counts as approval. Each numbered group is one small pull request with its own Verify line. Playwright runs against a local build (`python3 build.py && node e2e/local-server.mjs 8124 _site`, `BASE_URL=http://localhost:8124`), with `--retries=0` on chromium, webkit and mobile for the specs a task names.

Order (design D14): group 1 lands first and alone (small, unlocks everything). Group 2 is the URL switch: its pull requests go into the integration branch `learn-paths` in parallel and merge to `main` together, so URLs change once. Group 3 (view transitions inside the game) needs no paths and starts on day one, in parallel with groups 1 and 2. After the switch, groups 4 to 8 run in parallel.
