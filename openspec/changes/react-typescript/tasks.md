# Tasks

Tasks marked **[OWNER]** can only be done by the owner. Every other task is for a builder. "Verify:" says how a task is checked. Every PR from phase 1 on keeps the Playwright suite green on its preview (chromium, webkit, mobile) and the performance gates within budget (performance-budget spec), and every migration PR's description starts with `Locks:` and the views it locks (design D12). A migration PR may change selectors, waits and URL forms in `e2e/`, never what a test expects a Player to see or what is stored or sent (design D10); the description lists every changed spec line.

Re-phased 2026-10-20 for the owner's decisions N1 to N8 (design D4, D5, D9, D14 to D18, Migration plan). Phase 1 is framework-neutral tooling; phase 2 is the React Router framework-mode shell on Workers serving the Legacy views. Task groups: 0 before building, 1 phase 1, 2 and 3 phase 2 (shell, then logic), 4 phase 3 (shell pieces), 5 to 7 phase 4 (views), 8 phase 5 (interactive views), 9 phase 6 (retire legacy), 10 phase 7 (3D), 11 phase 8 (server voice), 12 phase 9 (follow-on plans). Group numbers 4 to 10 are unchanged from the first plan; the old group 2 (TypeScript logic) is now group 3, the old group 3 (router and paths) is now group 2, and the old group 11 (plans) is now group 12.
